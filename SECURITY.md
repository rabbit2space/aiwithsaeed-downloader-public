# Security / امنیت

## فارسی

کوکی، توکن تلگرام، فایل پایگاه‌داده یا گزارش حاوی اطلاعات شخصی را در Issues عمومی منتشر نکنید. اگر توکن ربات لو رفت، آن را در BotFather باطل کنید. برای کوکی لو‌رفته، نشست مربوط به حساب را لغو کنید.

اگر بخش **Security → Report a vulnerability** در این مخزن فعال است، از آن استفاده کنید. در غیر این صورت، در یک Issue فقط درخواست راه ارتباط خصوصی بدهید؛ جزئیات آسیب‌پذیری و اطلاعات حساس را عمومی ننویسید.

این پروژه تضمین زمان پاسخ‌گویی یا برنامه پاداش باگ ندارد.

## English

Never post cookies, Telegram tokens, databases, or unredacted logs in public issues.
Revoke an exposed bot token using BotFather; invalidate an exposed browser session
through the account provider.

Use **Security → Report a vulnerability** if available. Otherwise, open an issue
requesting a private contact channel without disclosing exploit details or secrets.
There is no guaranteed response time or bug bounty program.
